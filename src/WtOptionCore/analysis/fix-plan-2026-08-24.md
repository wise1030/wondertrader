## 关键设计说明

1. **B05 时间注入路径**：ISignal 基类持有 `m_signalTime`（protected）。strategy 在 on_tick_batch（每批最先执行）与 on_trade 分发前调用 `setSignalTime(ctxTimeSeconds(_ctx))`。EMAFilter 对 secs<0 已有丢弃保护，跨日安全。
2. **B11 position source**：`OptionTradingGrid::setPositionSourceFn(fn)` 由 strategy 注入 `[this](code){ return _positions.count(code)?(int32_t)_positions[code]:0; }`。_positions 仅 worker 线程读写，OTD::getPosition 消费点（computeOurMarkets/willBeActive）均在 worker 线程，无线程问题。
3. **B11b QM_CLOSE 新语义**：AUTO 态 `enable_auto_close && |pos| > max(close_thresh,0)` 进入 CLOSE；CLOSE 态仅激活减仓方向（pos<0 开 bid 收货？——注意：空头仓位(pos<0)需买入平仓 → enable_bid；多头 enable_ask），pos==0 回 AUTO。close_pos_thresh=0 时任何非零仓即触发（兼容原语义），彻底消除双边死区。
4. **B22a 语义**：TPS 计数单位 = 实际发单事务数（quote≈1 次 API 调用计 2、撤单按实发笔数）。cancel_only 返回本次实发撤单数而非终身累计。
5. **B04 combo onFill 匹配键**：localid。SpreadComboOrder/SynComboOrder 各实现 `bool onOrderFill(uint32_t localid, double fillQty)`（返回是否命中任一腿），内部按已成交量差值驱动腿2/补量，替代原"首触即满额"逻辑。
